# 二十张极简风景泛化测试报告

测试日期：2026-08-25

## 结论

当前程序具有**中等、但有清晰边界的泛化能力**。它已经能稳定处理大面积、横向分层的风景结构，但还不能稳定保住画面中面积很小、语义却很重要的主体。

- 严格视觉评估：可直接使用 8/20，部分保留 8/20，不合格 4/20。
- 程序与 SVG 结构验证：19/20 通过；第 09 张为倒影角色/调色板元数据契约不适配，生成本身成功，视觉结果可用。
- 同参数、同种子独立复跑：SVG 20/20、JSON 20/20 逐字节一致。
- 闭合小洞与漏底检查：20/20 为零；没有检测到图层间微洞或画布边缘漏底。
- 所有结果均由本地离线程序生成，没有使用任何生图能力。

换句话说：几何稳定性、可重复性和防缝隙已经具备；内容选择的泛化仍然不够。当前最主要的问题不是“画坏轮廓”，而是“没有判断出哪个小东西必须留下”。

## 测试设置

所有图片使用同一组参数，没有逐图调参：

```text
detail=0.35
paper=0.50
paper-style=rough
paper-density=1.00
grain-overlay=0.34
gradient-strength=0.30
color-mode=source
curve-smoothing=0.82
min-negative-gap=0.018
palette-size=6
max-shapes=10
seed=17
```

测试集覆盖：雪地、雾林、层叠山峦、湖面倒影、夜景、草地、海面、沙丘、极小人物、房屋、船、牛、树群等。平均大色块数为 6.2，范围为 2–10。

## 泛化边界

### 已经比较稳定

1. 大面积横向分层：山、雪线、天空、草坡、水面。
2. 颜色概括：同色系远近层级和轻度渐变能稳定输出。
3. 几何清洁度：本轮没有检测到细夹缝、小洞或画布边缘漏底。
4. 可重复性：固定种子后，20 张全部逐字节复现。
5. 特殊分型没有明显误触发：18 张走通用分型，1 张倒影，1 张夜景；此前的“彩色假背景”规则本轮 0 次触发。

### 仍然不稳定

1. 小面积高语义主体：人、船、房屋、牛、鸟、小树群会因为面积小而在区域合并阶段丢失。
2. 高调、低对比雾景：容易把主体和背景一起压平，或产生缺乏空间逻辑的色岛。
3. 紧凑主体的形状语义：即使检测到主体，也可能只保住面积和位置，轮廓会变成圆钝或错误的象形。
4. 倒影验证契约：第 09 张只需要 5 个角色就能成立，但验证器目前按更复杂的 7–10 角色场景检查，因此出现“视觉通过、结构验证失败”。

## 下一步优化优先级

最值得优先做的是“**小而重要的主体保护**”，不是继续增加整体细节。可以在分块合并前增加一个与面积无关的显著性保留通道：综合局部对比、边缘闭合度、孤立程度和构图位置，保留 1–3 个小型主体候选；同时限制其轮廓复杂度，避免把噪点误认成对象。

第二优先是为高调雾景增加低对比保护，避免主山体被拆散。第三优先才是放宽倒影验证器，让 5 角色的简洁倒影成为合法输出。
